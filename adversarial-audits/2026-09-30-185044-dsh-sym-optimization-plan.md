## 1. 任务清单

### ADV-P0-01｜把"接口契约"变成可发现的事实

- **来源发现**：AUD-TEST-001（S1）、AUD-DOC-002（S2）
- **优先级**：P0
- **主要模块**：`AGENTS.md`（项目级）
- **产物**：新增"接口契约"一节，逐个列出导出函数的**签名与返回契约**，重点标注：
  - `expandQuoteMarks(messages)` → **无变化返回 `null`**；`message.content` **必须是块数组**
  - `proseOfMessage(message)` → 传入 **message 对象**（非 id）；无文本块返回 `null`
  - `rememberProse(id, prose)` → 按 id 存，超 400 条淘汰最旧
  - `isPeakTime(ms, holidays)` → 峰段 `09:00–12:00`、`14:00–18:00`，含起点不含终点
  - `readProcessMemory()` → `{rss, heapUsed}` 或 `null`
- **允许路径**：`AGENTS.md`
- **禁止路径**：`lib/**`（本卡只写文档）
- **验收**：
  ```bash
  grep -c "expandQuoteMarks\|proseOfMessage\|isPeakTime" AGENTS.md
  ```
- **预期结果**：三个关键函数均有签名条目；每个"返回 null"的语义都被写明
- **停止条件**：梳理时发现文档与实现不符 → **以实现为准**，并把差异记为新的 AUD
- **回滚**：还原 `AGENTS.md`
- **时间线回写**：待回写

### ADV-P1-01｜补失败路径断言

- **来源发现**：AUD-TEST-002（S2）
- **优先级**：P1
- **主要模块**：`test/host.test.mjs`
- **产物**：对每个导出函数补非法入参断言（`null`、非数组、缺字段、超界）
- **允许路径**：`test/**`
- **禁止路径**：`lib/**`
- **验收**：
  ```bash
  npm test
  grep -c "throws\|rejects\|assert.equal(.*null" test/host.test.mjs
  ```
- **预期结果**：全部通过，且失败路径断言数 ≥ 6
- **停止条件**：发现某函数对非法入参**抛错**而非返回 `null` → **这是契约不一致**，记为新 AUD 再决定
- **回滚**：还原测试文件
- **时间线回写**：待回写

### ADV-P1-02｜测试助手不再污染全局

- **来源发现**：AUD-TEST-003（S2）
- **优先级**：P1
- **主要模块**：`test/helpers/load-client.mjs`
- **产物**：加载前保存原 `globalThis.window`，调用后恢复；多次加载互不影响
- **允许路径**：`test/**`
- **禁止路径**：`lib/**`
- **验收**：连续加载两次后，断言两次拿到的导出**互相独立**（例如模块级缓存不串）
- **预期结果**：测试顺序改变不影响结果
- **停止条件**：发现客户端模块**本身**依赖单例全局（而非 shim 造成）→ 记为新 AUD，不在本卡处理
- **回滚**：还原助手
